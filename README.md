# September

Boston starts over every September. Thousands of students arrive in the same week,
move into the same streets, and learn the same city at the same time.

This is a website about that month, built on live public data.

- Street cleaning by street and side — City of Boston
- Trash day, food truck schedule, street occupancy permits — City of Boston
- Planned T closures — MBTA v3
- Campus events, filtered to what's open to anyone — Northeastern and MIT public calendars
- Deposit deadlines — computed from Massachusetts law

No API keys. Rebuilds three times a day. Open source.
